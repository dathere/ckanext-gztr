The United States Census Bureau provides GIS mapping files, in particular [Topologically Integrated Geographic Encoding and Referencing (TIGER)]((https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html)) files that represent the U.S. Census Bureau's geographic spatial data.

These files are provided each Gregorian year in various formats, commonly using shapefiles.

## Tutorial: How to set up a geospatial collection of counties for a U.S. State with ckanext-gztr using Python

We'll demonstrate how to catalog the counties for a U.S. state from a TIGER/Line Shapefile on a CKAN instance with ckanext-gztr installed. The steps should be similar for other shapefiles provided by the data source which you can modify.
