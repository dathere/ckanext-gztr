The [3D National Hydrography Program (3DHP)](https://www.usgs.gov/3d-hydrography-program) is the latest systematic remapping of U.S. hydrography supported by the [U.S. Geological Survey](https://usgs.gov).

## Jupyter Lab Tutorial

In the Jupyter notebook below you can learn how to add a geospatial collection to your CKAN instance for your region based on 3DHP.

Note that this process is based on the large [3DHP data download from ScienceBase](https://www.sciencebase.gov/catalog/item/69743a65d4be0260181a121e), which is about 20GB compressed and about 60GB when uncompressed as a GeoPackage file.

Therefore we won't download the file in the interactive Jupyter Lab, there's an assumption that you'll run the notebook locally so you can also click the download button instead of the interactive Jupyter Lab to run the process on your local device.
