**[Geoconnex](https://geoconnex.us/) aims to make water data as easily discoverable, accessible, and usable as possible**.

![Geoconnex diagram](/media/geoconnex-diagram.png)

The Geoconnex project provides technical infrastructure and guidance for creating an open, community-contribution model for a knowledge graph linking hydrologic features in the United States, published in accordance with [Spatial Data on the Web](https://www.w3.org/TR/sdw-bp/) best practices as an implementation of [Internet of Water](https://github.com/opengeospatial/SELFIE/blob/master/docs/demo/internet_of_water.md) principles.

The CKAN-Geoconnex integration is built in collaboration between [datHere](https://dathere.com), the [Center for Geospatial Solutions](https://cgsearth.org/), and the [United States Geological Survey](https://www.usgs.gov/).
