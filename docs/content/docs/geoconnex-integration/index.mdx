There are plenty of CKAN instances that catalog **water data** 🌊, including the [New Mexico Water Data Catalog](https://catalog.newmexicowaterdata.org) and the [Texas Water Data Hub](https://txwaterdatahub.org). To make it easier to share water data from CKAN instances with the [Geoconnex](/docs/geoconnex-integration/about-geoconnex) knowledge graph, the ckanext-gztr CKAN extension provides Geoconnex-specific features and infrastructure for connecting these software systems.

## Syncing CKAN water data hubs with Geoconnex

If you have a CKAN instance that stores water data, this documentation section should help you understand how to enable synchronization between your CKAN datasets and geospatial collections with Geoconnex to contribute to the open global water data knowledge graph.
