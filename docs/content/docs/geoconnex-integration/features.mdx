If your CKAN instance stores CKAN datasets or custom geospatial features about real-world hydrologic features with ckanext-gztr, you can opt-in to retrieve and share data with the Geoconnex water data knowledge graph.

By enabling the Geoconnex integration for your CKAN instance, your instance will be provided dataset discovery in Geoconnex among participating Geoconnex-enabled CKAN instances.

Explore the multiple benefits that this synchronization has to offer here, and on the next page we'll cover how to enable Geoconnex capabilities for your CKAN instance.

## Mint Persistent Identifiers (PIDs) for your CKAN instance's data

![Mint Geoconnex PID example](/media/mint_geoconnex_pid_example.excalidraw.svg)

By enabling the Geoconnex integration, your compatible CKAN datasets should be minted a Geoconnex persistent identifier (PID) as a new URL to link to your CKAN dataset's landing page. We use the CKAN dataset `id` value from the `/api/3/action/package_show` endpoint as the PID unique ID value, along with a namespace you'll define when enabling the Geoconnex integration such as `New_Mexico_Water_Data_Catalog`.

For example review the following diagram then the bullet point list afterwards as they relate to the CKAN-Geoconnex integration:

![Geoconnex diagram](/media/geoconnex-diagram.png)

- **Persistent IDs (URL) (on the left side)**: your CKAN dataset's minted PID (e.g. `https://geoconnex.us/ckan/New_Mexico_Water_Data_Catalog/2e27c468-37a6-435d-b57f-1b8f9cea3717`)
- **Observed or Modeled Data**: a CKAN dataset
- **Landing page**: a CKAN dataset's landing page (e.g. [https://catalog.newmexicowaterdata.org/dataset/2e27c468-37a6-435d-b57f-1b8f9cea3717](https://catalog.newmexicowaterdata.org/dataset/2e27c468-37a6-435d-b57f-1b8f9cea3717))
- **Structured/Linked Data (JSON-LD)**: JSON-LD that describes the CKAN dataset and includes reference PIDs that the CKAN dataset is about
- **Persistent IDs (URL) (on the right side)**: Geoconnex reference feature PID(s) based on geospatial features you've selected in the dataset publisher gazetteer (e.g. Santa Fe, so the PID is [https://geoconnex.us/ref/places/3570500](https://geoconnex.us/ref/places/3570500))

## Expose Geoconnex-compatible JSON-LD linked data on CKAN dataset landing pages

With the Geoconnex integration enabled along with the relevant configuration values:

```ini tab="INI"
# == ckanext-gztr | Geoconnex options (more info at https://gztr.dathere.com/docs/geoconnex-integration) ==
ckanext.gztr.geoconnex.enabled = true
# The namespace that should exist in the namespaces/bulk/ckan directory at https://github.com/internetofwater/geoconnex.us
ckanext.gztr.geoconnex.namespace = New_Mexico_Water_Data_Catalog
# Embeds Geoconnex-compatible JSON-LD within each compatible CKAN dataset's landing page
ckanext.gztr.geoconnex.enable_dataset_jsonld = true
```

```dotenv tab="ckanext-envvars"
# == ckanext-gztr | Geoconnex options (more info at https://gztr.dathere.com/docs/geoconnex-integration) ==
CKANEXT__GZTR__GEOCONNEX__ENABLED=true
# The namespace that should exist in the namespaces/bulk/ckan directory at https://github.com/internetofwater/geoconnex.us
CKANEXT__GZTR__GEOCONNEX__NAMESPACE=New_Mexico_Water_Data_Catalog
# Embeds Geoconnex-compatible JSON-LD within each compatible CKAN dataset's landing page
CKANEXT__GZTR__GEOCONNEX__ENABLE_DATASET_JSONLD=true
```

Your compatible CKAN datasets should include JSON-LD embedded in each landing page's HTML. For example the JSON-LD may look similar to the following:

```json
{
  "@context": {
    "@vocab": "https://schema.org/",
    "gsp": "http://www.opengis.net/ont/geosparql#"
  },
  "@id": "https://geoconnex.us/ckan/New_Mexico_Water_Data_Catalog/2e27c468-37a6-435d-b57f-1b8f9cea3717",
  "@type": "Dataset",
  "about": [
    {
      "@id": "https://geoconnex.us/ref/places/3570500"
    }
  ],
  "name": "Northwest Well and City Wellfield Water Level Monitoring Program",
  "provider": {
    "@type": "Organization",
    "name": "City of Santa Fe"
  },
  "url": "https://catalog.newmexicowaterdata.org/dataset/2e27c468-37a6-435d-b57f-1b8f9cea3717"
}
```
