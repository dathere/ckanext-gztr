ckanext-gztr is an open-source [CKAN](https://ckan.org) extension that provides interactive gazetteer maps to associate datasets with geospatial data. You may provide custom map features using GeoJSON files as presets or enable drawn polygon features.

For example, you may find ckanext-gztr useful in these scenarios:

| Role | Example use case |
| ---- | ---------------- |
| Dataset publisher | Graphically associate datasets with geospatial features by either drawing custom polygons or selecting preset features related to your dataset such as landmarks, cities, counties, provinces, states, etc. |
| Public user | Search for datasets that have associated geospatial features which intersect with a bounding box that you can draw on a map. Optionally search by an address and preview preset map features before drawing your bounding box. |
| CKAN instance sysadmin | Install ckanext-gztr for your organization's CKAN instance, select default map regions, add preset geospatial features, and customize other configuration options. |
