ckanext-gztr is a [CKAN](https://ckan.org) extension that provides interactive gazetteer maps to associate datasets with geospatial data. You may provide custom map features using GeoJSON files as presets or enable drawn polygon features.

For example, you may find ckanext-gztr useful in these scenarios:

| Role | Example use case |
| ---- | ---------------- |
| CKAN instance sysadmin | Provide data curators a way to graphically associate datasets with preset map features such as landmarks, cities, counties, provinces, states, etc. |
| Dataset author | Draw custom regions and/or select preset features related to your dataset |
| Public user | Search datasets by either drawing a bounding box over a region on a map or by feature name, while also viewing map previews for each dataset in the results |

The ckanext-gztr extension can assist in providing solutions to the first two use cases, and can work well with the [ckanext-spatial](https://github.com/ckan/ckanext-spatial) extension for helping resolve the public user's search use case.
