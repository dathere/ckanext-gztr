ckanext-gztr is a [CKAN](https://ckan.org) extension that provides interactive gazetteer maps to associate datasets with geospatial data. You may provide custom map features using GeoJSON files as presets or enable drawn polygon features.

For example, you may find ckanext-gztr useful in these scenarios:

| Role | Example use case |
| ---- | ---------------- |
| Dataset curator | Graphically associate datasets by either drawing custom regions or selecting preset features related to your dataset including preset map features such as landmarks, cities, counties, provinces, states, etc. |
| Public user | Search datasets by drawing a bounding box over a region on a map along with searching by address and viewing preset map features. Also view map previews for datasets in search results. |
| CKAN instance sysadmin | Install ckanext-gztr for your organization's CKAN instance |
