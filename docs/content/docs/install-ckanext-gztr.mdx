# Installation and Setup

We assume you're familiar with setting up CKAN extensions.

In this installation guide we'll use a CKAN source install set up for development on Ubuntu 24.04 and we'll refer to the default installation location of `/usr/lib/ckan/default/src/ckan` during these steps along with the configuration file at `/etc/ckan/default/ckan.ini`. Our installation is based on [`ckan-devstaller`](https://ckan-devstaller.dathere.com).

<Callout title="Just trying out the extension?" type="info">If setting up a new CKAN instance for experimenting we suggest using [ckan-devstaller](https://ckan-devstaller.dathere.com). Note that you should **not** use ckan-devstaller for production usage.</Callout>

<Callout title="Where have we tried ckanext-gztr?" type="info">The ckanext-gztr extension has worked on CKAN 2.11.4 and hasn't been verified to work for other versions.</Callout>

<Steps>
<Step>

## Activate your virtual environment and change directory to `/usr/lib/ckan/default/src`

Ensure your terminal is running in your instance's virtual environment before continuing and that you're in the `/usr/lib/ckan/default/src` directory so that we may install extensions here.

```bash
cd /usr/lib/ckan/default/src
. ../bin/activate
```

</Step>
<Step>

## Install ckanext-scheming

The ckanext-gztr extension relies on [ckanext-scheming](https://github.com/ckan/ckanext-scheming) to add the interactive gazetteer to the new dataset form.

Run the following in `/usr/lib/ckan/default/src` to install the ckanext-scheming extension:

```bash
pip install -e "ckanext-scheming@git+https://github.com/ckan/ckanext-scheming.git"
```

Then in your CKAN config file (e.g., `/etc/ckan/default/ckan.ini`) for `ckan.plugins` add `scheming_datasets`. For example:

```ini
ckan.plugins = activity scheming_datasets
```

Also add the following lines in the `/etc/ckan/default/ckan.ini` file (e.g. right below the line with `ckan.plugins`) for displaying the gazetteer in the dataset form:

```ini
# ckanext-scheming theme settings
scheming.presets = ckanext.scheming:presets.json ckanext.gztr:schemas/presets.yaml
scheming.dataset_schemas = ckanext.gztr:schemas/dataset.yaml
```

<Callout type="warning" title="Duplicate options">You may already having `scheming.presets` in `/etc/ckan/default/ckan.ini` if you installed using [ckan-devstaller](https://ckan-devstaller.com), so update the existing value instead.</Callout>

If you already have a running CKAN instance with ckanext-scheming installed and a custom schema YAML file then you'll want to add the following fields to your schema YAML file for the dataset publisher gazetteer to appear in the dataset metadata form:

```yaml

# ckanext-gztr fields
# Interactive React gazetteer widget
- field_name: gazetteer
  label: Indicate Spatial Coverage
  form_snippet: gazetteer_widget.html
  display_snippet: null
  validators: ignore_missing gazetteer_validator
  output_validators: scheming_load_json
# Full GeoJSON as a FeatureCollection from user's selection in data publisher gazetteer
- field_name: spatial_full
  label: Spatial Full
  form_snippet: text.html
  form_placeholder: Filled in automatically as you select areas above.
# Simplified spatial_full geometry for indexing with Solr
- field_name: spatial
  label: Spatial
  display_snippet: null
  form_snippet: text.html
  form_placeholder: Filled in automatically as you select areas above.
# Place keywords as a comma-separated string
- field_name: place_keywords
  label: Place Keywords
  display_snippet: text.html
  form_attrs:
    data-module: place_keywords
```

</Step>
<Step>

## Install ckanext-gztr

Run the following in an activated virtual environment:

```bash
cd /usr/lib/ckan/default/src
git clone https://github.com/dathere/ckanext-gztr.git
cd ckanext-gztr
pip install -e .
pip install -r requirements.txt
```

Then add `gztr` to your `ckan.plugins` in your `/etc/ckan/default/ckan.ini` file:

```ini
ckan.plugins = activity scheming_datasets gztr
```

</Step>

<Step>

## Verify ckanext-gztr works as expected

Now the interactive gazetteer should be available on the form for adding and editing a dataset along with a "Spatial" field which is used to save the selected features along with a public search map gazetteer.

For example you can run a local CKAN instance by running the following in your activated virtual environment:

```bash
cd /usr/lib/ckan/default/src/ckan
ckan -c /etc/ckan/default/ckan.ini run
```

Then you should have your local CKAN instance running which you can open in your web browser at [http://localhost:5000](http://localhost:5000). If you visit the Datasets page at [http://localhost:5000/dataset](http://localhost:5000/dataset) then you should see an interactive search gazetteer in the left column to search by bounding box intersections and a data publisher gazetteer in the new dataset form.

If you visit [http://127.0.0.1:5001/api/3/action/status_show](http://127.0.0.1:5001/api/3/action/status_show) then there should be a JSON response where `gztr` is present in the `result.extensions` array.

</Step>
