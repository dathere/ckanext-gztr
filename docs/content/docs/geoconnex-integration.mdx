There are plenty of CKAN instances that involve **water data**, including the [New Mexico Water Data Catalog](https://catalog.newmexicowaterdata.org) and the [Texas Water Data Hub](https://txwaterdatahub.org). To make it easier to share water data from CKAN instances with the Geoconnex knowledge graph, the ckanext-gztr CKAN extension provides Geoconnex-specific features and infrastructure for connecting these software systems.

## About Geoconnex

Here's an excerpt from the [Geoconnex](https://geoconnex.us/) documentation:

The Geoconnex project provides technical infrastructure and guidance for creating an open, community-contribution model for a knowledge graph linking hydrologic features in the United States, published in accordance with [Spatial Data on the Web](https://www.w3.org/TR/sdw-bp/) best practices as an implementation of [Internet of Water](https://github.com/opengeospatial/SELFIE/blob/master/docs/demo/internet_of_water.md) principles.

In short, **Geoconnex aims to make water data as easily discoverable, accessible, and usable as possible**.

![Geoconnex diagram](/media/geoconnex-diagram.png)

The CKAN-Geoconnex integration is built in collaboration between datHere, the [Center for Geospatial Solutions](https://cgsearth.org/), and the [United States Geological Survey](https://www.usgs.gov/).
