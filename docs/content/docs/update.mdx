To keep ckanext-gztr up to date, you'll want to ensure that you're updating ckanext-gztr when a new release is published. You can **watch** [the GitHub repository](https://github.com/dathere/ckanext-gztr) to get notified when there is a new version released for ckanext-gztr.

Some releases may require you to modify your [configuration](/docs/configuration), so make sure to stay up to date on release notes as they are provided.
