---
title: "Update ckanext-gztr"
description: Learn how to update ckanext-gztr.
icon: PackagePlus
---

To keep ckanext-gztr up to date, you'll want to ensure that you're updating ckanext-gztr when a new release is published. If you keep the original configuration then you can perform a `git pull` within the `ckanext-gztr` directory to get the latest changes.

However if you customize the configuration then it is expected that the widgets will be rebuilt  to `ckanext/gztr/assets` and that when you pull changes there would be conflicts. One way to handle this is to restore changes for your output build and then run `git pull` followed by building the widgets again.
