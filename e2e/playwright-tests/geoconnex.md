# Geoconnex tests

There are several user stories that are tested for a CKAN instance's integration with [Geoconnex](https://geoconnex.us). Each user story is described in their corresponding markdown file in the `geoconnex` directory, however these will be displayed for you as this test suite is ran in the terminal.

For now, all of the tests will be ran sequentially for you from `geoconnex/tests.py`. **We put a delay of 45-60 seconds between each test and a slow factor for test operations so you can read the test description before each test is ran**. We'll print the test description to the terminal too so you don't have to leave the terminal. We encourage you to keep the terminal open where you run the `pytest` command on another monitor so that you can read the useful output provided during each test. Otherwise you can view the output after each test has ran along with the next test's description.

In a few seconds the first test's description will be printed and a pause of 60 seconds will occur. Read the description (you may need to scroll up on your terminal) before the test begins.
