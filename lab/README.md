# ckanext-gztr lab 🔬

This directory is meant to be ran as a Jupyter Lab environment for tutorials about [ckanext-gztr](https://gztr.dathere.com).

## Run this lab using mybinder.org

You can run this lab from your browser with [mybinder.org](https://mybinder.org) as its backend. Simply press the following link and wait a few seconds/minutes for the environment to spin up: [https://mybinder.org/v2/gh/dathere/ckanext-gztr/HEAD?urlpath=%2Flab](https://mybinder.org/v2/gh/dathere/ckanext-gztr/HEAD?urlpath=%2Flab)

## Run this lab in a local Jupyter Lab environment

```bash
git clone https://github.com/dathere/ckanext-gztr.git
cd ckanext-gztr/lab
uv venv
source .venv/bin/activate
uv pip install jupyterlab
jupyter lab
```
